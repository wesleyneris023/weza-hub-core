# Weza Hub Core

Crie o projeto inicial do WEZA HUB, uma plataforma SaaS profissional para gestão de clientes, sites e serviços digitais.

Use uma interface moderna, premium e corporativa, com visual clean, responsivo e preparado para desktop e mobile.

Crie apenas a estrutura inicial:

- Dashboard principal

- Menu lateral

- Cabeçalho

- Área de conteúdo

- Estrutura preparada para Clientes, Websites, Vendas, Assinaturas, Pagamentos, Manutenção e Faturamento.

Não crie dados fictícios nem funcionalidades complexas ainda.

Prepare a arquitetura para posteriormente conectar ao Supabase.
